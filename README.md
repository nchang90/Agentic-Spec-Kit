# Agentic Spec Kit

A collection of self-contained labs for building software and Azure
infrastructure with [Spec Kit](https://github.com/github/spec-kit), GitHub
Copilot, and executable engineering policy.

## Learning goal

The primary goal is to learn the
[official Spec Kit recommended process](https://github.github.com/spec-kit/quickstart.html)
from end to end. Azure and AVM provide the worked example; they do not replace
the Spec Kit workflow.

After completing the legacy-VM lab, you should be able to explain and use:

```text
CONSTITUTION → SPECIFY → CLARIFY → PLAN → CHECKLIST
             → TASKS → ANALYZE → IMPLEMENT → CONVERGE
```

You should also understand the boundary between each artifact: requirements
belong in the specification, technology belongs in the plan, work is derived
into tasks, and implementation is repeatedly converged against the approved
contract.

The central idea is simple:

1. Write standing rules in a constitution.
2. Specify observable outcomes without choosing an implementation.
3. Clarify ambiguity and review requirement quality.
4. Plan the technology and architecture.
5. Generate and analyze dependency-ordered tasks.
6. Implement and converge until the result matches the specification.

This repository makes that loop concrete with focused demo and lab runbooks, an
Azure Verified Modules (AVM) infrastructure example, and a verifier
that turns the infrastructure constitution into executable checks.

## Repository map

```text
.github/
├── copilot-instructions.md    # Repository guidance for Copilot
├── scripts/                   # Acceptance and infrastructure verifiers
└── skills/                    # Spec Kit commands and reusable domain knowledge
.specify/
├── memory/constitution.md     # Current Azure platform policy
├── templates/                 # Artifacts generated by Spec Kit
└── workflows/                 # Spec Kit workflow definitions
lab/
├── 01-legacy-vm/              # Two-part Spec Kit and AVM presentation demo
├── 02-weatherview/            # Free Static Web Apps exercise
└── 03-aimarket/               # AIMarket runbook, assets, and AVM Terraform
infra/                         # Current legacy-VM demo Terraform
specs/                         # Example generated specification artifacts
```

The checked-in constitution is intentionally infrastructure-focused. Individual
application runbooks replace it on a scratch branch or in a separate workspace,
then restore it during cleanup.

## Prerequisites

All exercises require:

- VS Code
- GitHub Copilot Chat
- Git
- Node.js LTS
- the Spec Kit CLI

Azure deployment labs additionally require the tools listed in their prep
checklists. Do not deploy before reading the cost and teardown sections.
