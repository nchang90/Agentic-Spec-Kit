# Labs

Each scenario lives in its own numbered directory with its runbook, supporting
assets, and any checked-in infrastructure.

| Lab | Scenario | Purpose |
|---|---|---|
| [01 — Legacy VM](01-legacy-vm/) | The Legacy VM That Never Needed a Public IP | Two presentation demos connecting Spec Kit requirements to governed AVM infrastructure |
| [02 — WeatherView](02-weatherview/) | Accessible static weather application | A free deployment exercise using Spec Kit, Bicep, and Azure Static Web Apps |
| [03 — AIMarket](03-aimarket/) | AI-assisted marketplace | A complete application and Azure Container Apps exercise with a pinned AVM Terraform reference |

The legacy-VM lab is the recommended presentation path. WeatherView and AIMarket
are independent follow-up exercises.
